# 🧩 Sopa de Letras

Juego de sopa de letras desarrollado en **HTML, CSS y JavaScript** como base para una futura versión en **Android**.

## 🎮 Características
- Tablero dinámico
- Palabras reales insertadas en el grid
- Selección por arrastre
- Validación de palabras encontradas
- Lista de palabras visibles
- Separación de lógica y UI

## 🛠️ Tecnologías
- HTML
- CSS
- JavaScript

## 🚀 Objetivo del proyecto
Este proyecto sirve como base sólida para:
- Aprender lógica de juegos
- Migrar posteriormente a Android Studio
- Implementar niveles, ayudas y mejoras
